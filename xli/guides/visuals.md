# Терминальный интерфейс: CLI, TUI и диаграммы

`xli run` — обычный поток текста, `xli repl` — диалог в строковом терминале,
`xli tui` — отдельный полноэкранный curses-интерфейс. В TUI агент и ввод работают
на одном asyncio-loop с регулярной передачей управления, без второго reader клавиатуры.

Сообщения отделены пустыми строками, инструменты — компактные строки активности.
При изменении размеров TUI заново раскладывает исходные события, а не обрезает
старые строки. Длинные слова, CJK и кириллица переносятся по ширине ячеек.
Диагностические логи не рисуются поверх curses; они остаются в каталоге logs.
`XLI_LOG_LEVEL=DEBUG` включает подробные консольные логи вне TUI.

## Сессии

```bash
xli session
xli session show --latest
xli session show 20261004-110934-863a7e
xli session list --json
xli session show --latest --json
```

Вместо Python repr список показывает ID, время, число событий, размер и первый
запрос. JSON остаётся машинным форматом без украшений. Старые текстовые tool_call
помечаются как вызовы **без записанного исполнения**; просмотр ничего не выполняет
и не изменяет историю на диске.

## Клавиши TUI

- Enter — отправить. Во время задачи новый текст остаётся черновиком.
- Up/Down — история запросов.
- PgUp/PgDn, Home/End — просмотр истории сообщений.
- Ctrl+U — очистить строку; Backspace — удалить последний символ.
- `/cancel` — отменить текущую задачу; `/clear` — очистить отображение.
- `/plugins` — плагины и авторы; `/tools` — каталог инструментов.
- В запросе разрешения: `y`, `n`, `a` (разрешать подтверждения до выхода), Esc — отказ.
- Ctrl+C / Ctrl+D — выход с отменой задачи и восстановлением терминала.

Минимальный полезный экран: около 21×8. Без TTY используйте CLI/REPL.
Цвета отключаются при перенаправлении вывода/NO_COLOR (FORCE_COLOR имеет приоритет).
Иконки Powerline/Nerd Fonts не требуются. Полная emoji/grapheme-кластеризация не
гарантируется: ширина сложных ZWJ-emoji зависит от терминала.

## Mind map / дерево

В ответах модели, плагинах и guides можно использовать Markdown-fence `mindmap`
или `tree`. Отступы задают родителей, порядок сохраняется:

```mindmap
XLI
  Интерфейс
    CLI / REPL
    TUI
  Плагины
    Авторство
    Инструменты
    Состояние
  Проверки
    Unit tests
    FakeProvider
```

Также поддерживается `mermaid` с первой строкой `mindmap` и корнем `root((Текст))`.
Это ограниченный терминальный поднабор, **не полный Mermaid**. Другие Mermaid-графы
отображаются как исходный код, без потери текста; браузер/Graphviz не запускаются.

## Столбчатая диаграмма

Fence `chart`: одна запись `подпись | число` на строку. Значения конечные,
неотрицательные; шкала нормируется по наибольшему значению.

```chart
CLI | 12
TUI | 9
Plugins | 16
```

Диаграммы используют максимум 200 записей, дерево — до 13 уровней.
Некорректный синтаксис и слишком узкое место отображаются обычным кодом.
Это статические диаграммы, а не интерактивный редактор графов или live-метрики.
Один renderer используется в CLI и TUI: плагины могут вернуть Markdown в summary
либо данные, которые модель объяснит и визуализирует в окончательном ответе.
